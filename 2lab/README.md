# Звіт до лабораторної роботи №2

## Тема
**Назва лабораторної роботи:** Верстка сайту компанії згідно з інструкцією (HTML/CSS)  
**Дисципліна:** Веб програмування

---

## Мета роботи
Практично застосувати CSS для оформлення семантичної HTML‑структури веб сторінки:  
- підключення зовнішнього CSS;  
- використання селекторів;  
- демонстрація каскаду та specificity;  
- робота з типами блоків і Box Model.

---

## Очікувані результати навчання
- створювати семантичну HTML‑структуру;  
- підключати зовнішній CSS‑файл через `<link>`;  
- використовувати селектори елементів, класів, id, атрибутів та універсальний селектор;  
- аналізувати конфлікти CSS‑правил, каскад і specificity;  
- застосовувати width, height, margin, padding, border та display;  
- пояснювати різницю між block, inline‑block та inline;  
- перевіряти застосування CSS через DevTools.

---

## Виконання роботи
Під час виконання лабораторної роботи було реалізовано:

- створено односторінковий сайт компанії «Акустична варта»;  
- використано семантичні теги: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`;  
- реалізовано різні типи CSS‑селекторів (елемента, класу, id, атрибута, універсальний, групування);  
- додано приклади каскаду та конфлікту CSS‑правил для демонстрації specificity;  
- застосовано Box Model (width, height, margin, padding, border, box‑sizing);  
- продемонстровано `display: block`, `inline`, `inline-block`;  
- додано стилізацію карток, попереджень, кнопки з transition та transform.
