
## Мета: Відображення та фільтрація сенсорів у DOM на прикладі навчального вебпроєкту «Акустична варта».

## Тема: Навчитися виводити дані сенсорів у DOM за допомогою JavaScript, динамічно формувати картки сенсорів, застосовувати CSS-класи залежно від стану та реалізувати фільтрацію списку за районом і статусом без використання форм, `localStorage` чи складних Browser API.

## 2. Опис виконаної роботи

Під час виконання роботи було розширено вебсторінку проєкту «Акустична варта» новою секцією **«Активні сенсори»** та реалізовано її динамічне наповнення і фільтрацію засобами JavaScript.

Основні елементи та функції, реалізовані в роботі:

### 2.1. Розмітка секції активних сенсорів (`HTML`)

Після блоку «Поточний моніторинг» додано секцію `<section class="active-sensors">`, яка містить:
- заголовок `<h2>Активні сенсори</h2>`;
- блок фільтрів (`.sensor-filters`) із випадаючим списком `<select id="district-filter">` (варіанти `all` — «Усі райони», `Галицький`, `Франківський`, `Шевченківський`) та чекбоксом `<input type="checkbox" id="critical-filter">` («Тільки критичні»);
- порожній контейнер `<div class="sensor-list"></div>` для динамічного рендерингу карток.

### 2.2. Оформлення карток і статусів (`CSS/SCSS`)

Додано стилі для картки сенсора (`.sensor-card`) та модифікатори стану залежно від рівня шуму:
- `.sensor-card--normal` — для нормального рівня шуму;
- `.sensor-card--warning` — для попереджувального рівня шуму;
- `.sensor-card--critical` — для критичного рівня шуму.

### 2.3. Логіка рендерингу та фільтрації (`JavaScript`)

Для роботи з DOM і даними сенсорів використано такі підходи та функції:
- вибірка елементів сторінки через `document.querySelector()` для `.sensor-list`, `#district-filter` та `#critical-filter`;
- робота з масивом об'єктів `sensors` (або наявними об'єктами сенсорів з попередніх робіт) із полями `id`, `district`, `location`, `noiseLevel` та `status`;
- функція `createSensorCard(sensor)` — створює елемент `<article>`, додає базовий клас та клас статусу, заповнює текстові поля через `textContent` і повертає сформовану картку;
- функція `renderSensors(sensorArray)` — очищує `.sensor-list` через `replaceChildren()` та додає картки переданого масиву;
- функція `applyFilters()` — зчитує вибраний район (`districtFilter.value`) і стан чекбокса (`criticalFilter.checked`), відбирає елементи через `.filter()` і викликає `renderSensors(filteredSensors)`;
- обробники події `"change"` (`addEventListener("change", applyFilters)`) на обидва елементи фільтрації.

## 3. Реалізація основної логіки

Під час виконання завдання було реалізовано:

1. **Початкове відображення списку.** Виклик `renderSensors(sensors)` після завантаження сторінки для виведення всіх наявних сенсорів.
2. **Генерацію DOM-елементів.** Програмне створення карток і вкладених текстових полів (ID, район, локація, рівень шуму, статус) без дублювання статичної розмітки в HTML.
3. **Візуальну диференціацію статусів.** Підключення класу стану `sensor-card--<status>` для швидкого розпізнавання станів `normal`, `warning` і `critical`.
4. **Очищення контейнера перед перемальовуванням.** Скидання попередніх карток перед виведенням нового набору даних, щоб уникнути дублювання.
5. **Комбіновану фільтрацію.** Одночасне врахування вибраного району та прапорця «Тільки критичні» з коректною обробкою випадків, коли підходящих сенсорів немає (порожній список).

## 4. Взаємодія з DOM та обробка подій

У лабораторній роботі використано базові механізми маніпуляції DOM і подій у JavaScript:

- **Пошук вузлів DOM** — отримання посилань на контейнер карток та елементи керування фільтрами через `document.querySelector()`.
- **Створення та вставка вузлів** — формування елементів через `document.createElement()` і додавання їх у дерево документа.
- **Безпечне виведення тексту** — заповнення даних через `textContent`.
- **Реакція на зміну стану фільтрів** — підписка на подію `"change"` для `select` та `checkbox`, яка запускає перерахунок відфільтрованого масиву та оновлення відображення.

## 5. Інтеграція з вебінтерфейсом

Секцію «Активні сенсори» органічно вбудовано в наявну сторінку проєкту «Акустична варта» після секції «Поточний моніторинг».

Інтерфейс дозволяє користувачу:
- переглядати список активних сенсорів із ключовими показниками;
- відфільтровувати сенсори за обраним районом або повертати перегляд усіх районів (`all`);
- залишати лише сенсори зі статусом `critical` або поєднувати обидва фільтри одночасно;
- бачити візуальну різницю між станами `normal`, `warning` та `critical`.

## 6. Результат роботи

У результаті виконання роботи на сторінці проєкту «Акустична варта» з'явилася інтерактивна секція відображення та фільтрації сенсорів.

Реалізований код коректно відображає початковий список сенсорів, оновлює його під час зміни фільтрів, оформлює різні статуси та залишає контейнер порожнім за відсутності збігів, не ускладнюючи проєкт зайвою функціональністю.
