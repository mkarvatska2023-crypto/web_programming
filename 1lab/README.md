# Статичний блог «Мої 3 найкращі міста світу»

Лабораторна робота №1 з дисципліни «WEB-програмування».

## Опис проєкту
Вебсайт містить інформацію про 3 улюблені міста світу (Київ, Париж, Токіо), виконаний за допомогою семантичної HTML-розмітки без використання CSS та JavaScript.

## Структура
- `index.html` — Головна сторінка
- `city-kyiv.html`, `city-paris.html`, `city-tokyo.html` — Окремі сторінки міст
- `form.html` — Форма зворотного зв'язку для пропозицій
- `images/` — Графічні матеріали
